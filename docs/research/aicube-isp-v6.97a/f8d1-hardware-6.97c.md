# STC32G144K246 硬件选项与仿真配置

以下偏移从 ISP 载荷的 `04` 命令字按零计数。函数地址对应 AiCube-ISP 6.97C。`F8D1` 型号记录在 `505488`，由标志 `002CD2DB` 取出选项组 `59`。`48BDA0 → 48BFAF` 选择 `520118` 的 27 项表。`48D1D0` 把界面选择写成 16 字节选项，`44B760` 组装 41 字节主体。发送前加 `04 00 00 5A A5`。

[完整控件表](f8d1-option-table.md)由 [提取脚本](dump-f8d1-options.py) 直接从 EXE 生成。原始字节和掩码指向 16 字节界面缓冲区。下载任务还在末尾附加三个 RS485 字节。带 `04` 偏移的项经过组包处理后写入片上配置。

## 串口、USB 与 SWD 仿真

| ISP 偏移 | 位 | 6.97C 主机含义 |
| --- | --- | --- |
| 39 | 7:6 | SWD 引脚编码。由控件 `0419` 填入 `opt[4]`。 |
| 39 | 5 | 模式 `8` 清零启用 SWD。其他模式由 `44B928` 强制置位。 |
| 40 | 7:6 | 串口仿真引脚编码。由控件 `0418` 填入 `opt[5]`。 |
| 40 | 5 | 控件 `0625`「使能USB仿真功能」的反相值。整字节经 `44B936` 拷贝。 |
| 43 | 7 | 模式 `6` 清零启用 USB-ICE。普通下载置位，此位和现有 USB-ICE 启用及还原抓包对应。 |

| `bit 7:6` | 引脚对（顺序为 RxD/TxD 或 SWD 数据/时钟） |
| --- | --- |
| `00` | `P3.0 / P3.1` |
| `01` | `P3.6 / P3.7` |
| `10` | `P1.6 / P1.7` |
| `11` | `P4.3 / P4.4` |

硬件页和 Keil 仿真页的 `DLGINIT` 资源 `00BE`、`00D5` 均给出上述顺序。`47F470` 把仿真页的 SWD 选脚同步到硬件页，`48F590` 反向同步。串口仿真回读显示的四个编码还可由 `446CEE` 的跳转表交叉确认。A/C 两版的组包原机器码都已验证这四个值，以及它们和模式位之间的组合。芯片写入后换脚以及 Link1D 通信仍需实板验证。

`4BB740` 根据主窗口的连接类型拦截一部分仿真制作方式，显示「当前端口不支持此功能」。离线组包验证能确认 `04` 的位移和取值。实际能否从所选连接制作 SWD 芯片，还受主机传输入口和 BSL 版本限制。

## 此前未对上的配置位

| `04` 偏移 | 位 | 含义和出处 |
| --- | --- | --- |
| 37 | 4 | 下次启用 USB-ISP，勾选时置位。控件 `0678`，`opt[14]`。 |
| 39 | 0 | 禁用 EEPROM 功能，勾选时置位。控件 `0612`，`opt[4]`。 |
| 41 | 6 | UART1 RxD/TxD 切换到 `P3.6/P3.7`，勾选时置位。控件 `0623`，`opt[0]`。 |
| 43 | 6 | CPU 指令模式。`0454` 列出 `0` 二进制模式和 `1` 源码模式。手册附录给出了两种模式的 `A5` 前缀规则。 |
| 26、36 | 全部 | 组包从 `opt[10]`、`opt[13]` 拷贝。F8D1 表没有写入这两个原始字节的控件。常规界面采集在 `48D209..48D221` 把它们初始化为 `FF`。 |
| 28 | 全部 | 常规 F8D1 分支保持组包缓冲区初始的 `FF`。同一函数的另一型号分支会使用此偏移。 |

原始 `opt[15]` 的 bit 7 控制本次是否下发 `04`，bit 6:5 选择 IRC 调节方式。该原始字节没有直接拷贝到 `04`，调节结果编码在 `29–35`。填充值控件 `0425` 同样没有 `04` 偏移。下载口令和 RS485 来自独立页面，其编码见 [总索引](README.md)。

静态分析覆盖 F8D1 界面表、选项包与主机分支。对保留位赋值或在芯片上试验未列出的组合，仍需设备侧证据。
