# AiCube-ISP 6.97C 硬件配置组包规则

入口是 `0x44B760`，输入对象中的硬件选项缓冲区位于对象偏移 `0x6E0`，输出缓冲区由调用者传入。函数先把 0x40 字节输出区填为 `FF`，再按照型号标志和连接模式写入字段。USB、串口和转接器都会复用这个主机侧组包函数。

## 返回长度

| `flags & 0x7F8000` | 输出长度 | 说明 |
| --- | ---: | --- |
| 小于 `0x1A8000` | `0x40` | 旧布局 |
| `0x168000`、`0x170000`、`0x178000`、`0x180000`、`0x188000`、`0x190000`、`0x198000`、`0x1A0000` | `0x28` | 混合布局，走 `0x44BBA7` |
| 大于等于 `0x1A8000`，且不是 `0x2C0000`、`0x2C8000` | `0x28` | 新布局 |
| `0x2C0000`、`0x2C8000` | `0x29` | 新布局追加字节 `0x28` |

## 新布局

新布局覆盖 `0x44B82D` 至 `0x44BA67`。下表使用输入选项缓冲区的相对偏移表示 `opt[n]`，运行时频率和修调字段使用对象成员偏移表示。

| 输出偏移 | 来源或变换 | 静态地址 |
| ---: | --- | ---: |
| `0x03` | `((~opt[0x10] & 0x02) << 3)` | `0x44B77D` |
| `0x04` | `opt[0x11]` | `0x44B790` |
| `0x06` | `((~opt[0x10] & 0x04) << 2)` | `0x44B79C` |
| `0x07` | `opt[0x12]` | `0x44B7B0` |
| `0x15` | `opt[0x0A]` | `0x44B82D` |
| `0x16` | 对象 `+0xF7C` 的修调值 | `0x44B839` |
| `0x17` | `0x2A0000` 族按 `opt[0x0C]` 和频率阈值计算 | `0x44B858` |
| `0x18..0x1B` | 对象 `+0x11C`、`+0x11D` 的频率字节 | `0x44B890` |
| `0x1C..0x1E` | 对象 `+0x71A`、`+0x71B`、`+0x71C` | `0x44B8C0` |
| `0x1F` | `opt[0x0D]` | `0x44B8DB` |
| `0x20` | `(opt[0x0E] | 0x0C) ^ 0x02`，随后受 `opt[0x10]` 和动态调校状态影响 | `0x44B8E7` |
| `0x22` | `opt[0x04] | 0x20`，连接模式 8 会清除 bit 5 | `0x44B925` |
| `0x23` | `opt[0x05]` | `0x44B933` |
| `0x24` | `opt[0x00]` | `0x44B93F` |
| `0x25` | `opt[0x01]`，旧 BSL 且族为 `0x1E8000` 时异或 `0x10` | `0x44B94A` |
| `0x26` | `opt[0x02] | 0x80`，连接模式 6 会清除 bit 7 | `0x44B983` |
| `0x27` | `flags & 8` 时来自 `opt[0x03]`，`0x260000` 和 `0x2C8000` 有特殊变换，否则为 `FF` | `0x44B9B5` |
| `0x28` | `0x2C0000` 族写 `opt[0x0B]`，`0x2C8000` 族写 `0x7A - opt[0x0B]` | `0x44BA21` |

## 旧布局

旧布局从 `0x44BA6A` 进入，返回长度为 `0x40`。频率字段仍来自对象 `+0x11C`、`+0x11D`，但字段位置和方向控制字段不同。`0x44BBA7` 是另一条路径，频率位于 `0x18..0x1B`，看门狗位于 `0x26`，返回 `0x28`。

| 输出偏移 | 来源或变换 |
| ---: | --- |
| `0x17`、`0x19`、`0x1B`、`0x1D` | 频率字节的旧布局排列 |
| `0x1F` | `(opt[0x0E] | 0x0C)`，按 `opt[0x10]` bit 0 和族标志调整 |
| `0x20` | 对象 `+0x18C` |
| `0x37` | `opt[0x08]` |
| `0x3B` | 对象 `+0x71A` |
| `0x3C` | 对象 `+0x71B | 0x3F`，连接模式 6 清除 bit 0 |
| `0x3D` | `opt[0x02]`，旧布局特殊族会清除 bit 7 |
| `0x3E` | `opt[0x01]`，部分特殊族异或 `0x07` |
| `0x3F` | `opt[0x00]`，部分特殊族执行 `| 0x80` 后异或 `0x10` |

## 连接模式影响

连接模式值由下载任务传入，不属于型号族记录。

| 模式 | 影响 |
| ---: | --- |
| 6 | 清除输出 `0x26` bit 7，旧布局还清除 `0x3C` bit 0 |
| 8 | 清除输出 `0x22` bit 5 |
| 9、11、13、15 | 强制输出 `0x27` 为 0 |

F8D1 和 8H8K 族的输出长度和字段已结合既有抓包核对。其他型号族现在已经有静态分支分类和完整选项描述，设备端字段意义仍应按型号逐步验证。
