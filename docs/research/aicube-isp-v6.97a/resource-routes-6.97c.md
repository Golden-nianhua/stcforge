# AiCube-ISP 6.97C 型号族资源分支

下载任务在 `0x4C22C8` 根据型号族选择 8 个资源分支。型号族到分支编号的映射位于 `0x4C31A8`，分支目标表位于 `0x4C3188`。这些资源是主程序随附的二进制文件，当前只记录主机选择关系，不把资源内容误当作设备协议。

| 分支 | 目标地址 | 条件 | 条件成立 | 条件不成立 |
| ---: | ---: | --- | --- | --- |
| 0 | `0x4C22D7` | `esp+0x13 != 0` | `res12.bin` | `res66.bin` |
| 1 | `0x4C22F2` | `esp+0x13 != 0` | `res13.bin` | `res67.bin` |
| 2 | `0x4C230D` | `esp+0x13 != 0` | `res14.bin` | `res68.bin` |
| 3 | `0x4C2328` | `flags & 0x1C0 == 0x080` | 进入 3A | 继续判断 |
| 3A | `0x4C2338` | `esp+0x13 != 0` | `res15.bin` | `res69.bin` |
| 3B | `0x4C234C` | `flags & 0x1C0 == 0x100` | 进入 3C | 进入 3D |
| 3C | `0x4C235C` | `esp+0x13 != 0` | `res26.bin` | `res71.bin` |
| 3D | `0x4C236C` | `esp+0x13 != 0` | `res16.bin` | `res70.bin` |
| 4 | `0x4C237C` | `esp+0x13 != 0` | `res55.bin` | `res72.bin` |
| 5 | `0x4C2390` | `esp+0x13 != 0` | `res63.bin` | `res74.bin` |
| 6 | `0x4C23A4` | `esp+0x13 != 0` | `res57.bin` | `res73.bin` |

型号族映射如下。未列出的高编号族使用默认分支 6，和原程序的 `family-1 > 0x58` 默认跳转一致。

| 型号族范围 | 资源分支 |
| --- | ---: |
| `0x01–0x06`、`0x0F–0x10` | 0 |
| `0x07–0x08` | 1 |
| `0x09–0x0E`、`0x13–0x18` | 2 |
| `0x19`、`0x1C` | 3 |
| `0x1A–0x1B`、`0x1D–0x2B` | 4 |
| `0x2D–0x34` | 5 |
| `0x35–0x4B`、`0x4D–0x58` | 7 |
| `0x4C`、`0x59` | 6 |
| `0x5A` | 默认 7 |

最终重构时，资源分支应当只作为主机侧型号准备数据的来源。真正的 USB、串口和转接器传输后端由下载任务的连接模式单独选择。
