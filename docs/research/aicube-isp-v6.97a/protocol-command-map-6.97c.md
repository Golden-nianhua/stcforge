# AiCube-ISP 6.97C 主机侧命令路径

这份表只记录 6.97C 主机程序明确写入的命令字和发送结构。命令的最终设备端语义以已有抓包和芯片应答为准，无法从主机侧单独确定的项目保留为“待设备确认”。

## 普通 ISP 下载

发送和接收由 `0x44BDC0`、`0x44BCE0` 完成。USB 和串口上层都会构造相同的命令缓冲区，再交给对应传输后端。

| 命令字 | 发送结构 | 主机侧证据 | 当前解释 |
| ---: | --- | --- | --- |
| `00` | 单字节准备命令 | `0x44C672` | 建立下载任务的初始握手 |
| `01` | 8 字节缓冲区 | `0x44C7B7` | 读取或准备芯片状态，设备端字段待确认 |
| `02` | 地址或数据相关短命令 | `0x44CE9F`、`0x44CF40` | 读取或切换下载状态，需结合具体应答 |
| `04` | `04 00 00 5A A5` 加硬件配置载荷 | `0x44D036`、`0x44D068` | 写入硬件选项。载荷由 `0x44B760` 生成 |
| `05` | `05` 加当前口令及长度字段 | `0x44C809` | 下载口令准备或解锁 |
| `07` | `07` 加新口令数据 | `0x44D0D6` | 更新下一次下载口令 |
| `12` | 变长数据包 | `0x44CEE7` | 某些型号族的专用配置或数据阶段，设备端语义待确认 |
| `22`、`A2` | 数据块命令，具体值受状态位影响 | `0x44CD1D` 及其前置分支 | 程序区或扩展数据写入阶段，设备端语义需按 BSL 版本确认 |
| `26` | 命令头加 0x40 字节数据 | `0x44CBB6`、`0x44CC04` | 分块写入程序或用户数据 |
| `42` | 命令头加辅助数据块 | `0x44CCC4` | 制作 Link1D、Writer1A、U8W 等主控时的辅助数据路径 |
| `85` | 命令头加至多 0x80 字节数据 | `0x44CDFB`、`0x44CE03` | 另一种程序数据块路径，设备端语义待确认 |

普通程序块会先写入块地址和长度，再检查状态包的低四位和确认字节 `0x54`。块大小、数据区起点和是否保留 EEPROM 由型号族、硬件选项和下载模式共同决定。

## IRC 和硬件选项

| 功能 | 主机入口 | 关键命令或数据 |
| --- | ---: | --- |
| USB 状态读取 | `0x43E1F0` | 解析芯片状态并填充对象成员 |
| USB 预置 IRC | `0x43EB30`、`0x43EFC0` | 根据型号状态和预置频率表生成设置阶段数据 |
| 串口动态 IRC | `0x4413F0`、`0x440CE0` | 多轮候选频率、测量、选值和写入，型号族分支不同 |
| 硬件配置 | `0x44B760` | 先按型号标志选择 `0x40`、`0x28` 或 `0x29` 字节布局，再由连接模式调整部分位 |

## 用户命令复位

用户命令复位不使用 ISP 命令字。主机根据界面配置打开应用侧 HID 或 COM 设备，HID 写出 65 字节报告，COM 直接写出最多 32 字节命令，随后重新进入 ISP 下载入口。

## 离线编程器

| 命令 | 用途 | 位置 |
| ---: | --- | ---: |
| `F1 00` | 连接编程器并开始准备 | `0x449440` |
| `F2` | 普通串口离线镜像数据块，三字节大端偏移，最多 128 字节 | `0x449440` |
| `F3 C8` | 结束第一段数据阶段 | `0x449440` |
| `F4` | 普通串口发送离线镜像数据块 | `0x44A36E` 至 `0x44A4D0` |
| `46`、`47`、`48` | 探针封装的数据准备阶段，单块最多 56 字节 | `0x449440` |
| `49` | 探针封装的离线镜像数据块 | `0x44A36E` 至 `0x44A4D0` |
| `40`、`01`、`02` | 探针额外准备命令 | `0x44A197` 至 `0x44A310` |

离线镜像头部占 `0x800` 字节，程序数据从 `0x800` 开始，空白区域填充 `FF`。普通离线下载使用模式 4，制作 Link1D、Writer1A、U8W 主控使用模式 7，并通过 `42` 或首块带 bit 5 的 `62` 传输辅助数据。

## 重构建议

主机实现可以拆成四层。型号数据库提供型号识别码、容量、配置描述和载荷布局，配置组包器根据数据库和用户选项产生 `04` 数据，ISP 会话层实现通用命令和应答，USB、串口、转接器和离线编程器作为独立传输后端。这样可以复用命令状态机，也能把不同型号族的字段差异限制在数据库和组包器中。
