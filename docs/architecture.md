# 架构与边界

```text
CLion → 自定义 MCS-251 GDB → GDB RSP 服务端 → STC USB-ICE → STC32G144K246
                 ↑
       SDCC CDB / HEX → 调试符号 ELF
```

第一目标仅支持 STC32G144K246 和当前 SDCC MCS-251 编译器。
源码调试、变量、栈回溯分阶段实现；不把尚未确认的协议字段包装成已验证功能。

## 寄存器协议

GDB 原始寄存器顺序与 46 字节 CPU 快照一致，采用大端：

| GDB 编号 | 名称 | 位数 | 快照偏移 |
| --- | --- | --- | --- |
| 0～15 | r0～r15 | 8 | 0～15 |
| 16～23 | wr16、wr18、wr20、wr22、wr24、wr26、wr28、wr30 | 16 | 16～31 |
| 24 | dpx | 32 | 32～35 |
| 25 | spx | 32 | 36～39 |
| 26 | psw | 8 | 40 |
| 27 | psw1 | 8 | 41 |
| 28 | pc | 32 | 42～45 |

位置 16～31 不能独立按字节寄存器寻址。初期不增加与原始寄存器重叠的伪寄存器。

## 调试器地址映射

| GDB 地址 | 含义 |
| --- | --- |
| `00000000..00003FFF` | EDATA，空间号 01；普通 RAM 读取仍待上板验证 |
| `00010000..0002FFFF` | XDATA，空间号 02；来自驱动静态路径，待上板验证 |
| `00FC2800..00FFFFFF` | 程序区，断点写入使用空间号 05，读取目前来自显式指定的本地 HEX |
| `10000080..100000FF` | SFR 虚拟窗口，映射空间号 04 的 `80..FF` |

SFR 与 EDATA 的同数值地址必须分开，不能把 RAM 的 `A8` 和 IE 寄存器混为一谈。
虚拟窗口不代表芯片拥有 32 位物理地址总线。

程序镜像读取可由显式指定的本地 HEX 提供，日志和文档必须说明来源。
除断点专用路径外，不允许通过普通写内存命令修改程序区。

RSP 内存图把程序区声明为可补丁的调试 RAM 视图，以让 GDB 选择 `Z0` 软件断点。
这是调试访问能力描述，不代表程序存储器的物理实现，也不开放普通 `M` 代码写入。
